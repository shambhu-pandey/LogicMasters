# 1️⃣ Add Two Numbers (Linked List)

**Difficulty:** 🟡 Medium  
**Tags:** Linked List, Math, Simulation  

---

### 🧩 Problem Statement  
You are given two non‑empty linked lists representing two non‑negative integers.  
- Digits are stored in **reverse order**.  
- Each node contains a single digit.  
- Add the two numbers and return the sum as a linked list.  

---

### 💡 Approach  
1. Use a **dummy node** to simplify traversal and result construction.  
2. Maintain a `carry` variable for digit overflow.  
3. Traverse both linked lists simultaneously:  
   - Add corresponding digits + carry.  
   - Create a new node with `(sum % 10)`.  
   - Update carry as `(sum / 10)`.  
4. If one list ends earlier, continue with the other.  
5. If carry remains after traversal, add a new node.  
6. Return `dummy->next` as the head of the result list.  

---

### 💻 Your Code (Unchanged)

```cpp
/*
Definition of singly linked list:
class ListNode{
  public:
    int data;
    ListNode *next;
    ListNode() : data(0), next(nullptr) {}
    ListNode(int x) : data(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : data(x), next(next) {}
};
*/

class Solution {
    public:
        ListNode* addTwoNumbers(ListNode* &linkedList1, ListNode* &linkedList2) {
           ListNode* dummy = new ListNode(-1); // USE FOR TRAVERSAL  
           ListNode* curr  = dummy;
           int carry =0;
           while(linkedList1 != NULL || linkedList2!= NULL){
               int sum = carry;

               if(linkedList1) sum = sum + linkedList1->data;
               if(linkedList2) sum = sum + linkedList2->data;

               ListNode* newnode =  new ListNode(sum%10);
               carry = sum/10;

               curr ->next = newnode;
               curr = curr->next;
             
             if(linkedList1) linkedList1 = linkedList1->next;
             if(linkedList2) linkedList2 =  linkedList2->next;

           }
           if(carry){
            ListNode* newnode = new ListNode(carry);
              curr->next = newnode;
           }

           return dummy->next;
        }
};
```

---

### 📝 Dry Run Example  

**Input:**  
```
linkedList1 = [2 → 4 → 3]   // represents 342
linkedList2 = [5 → 6 → 4]   // represents 465
```

**Step-by-step addition:**  
- 2 + 5 = 7 → node(7)  
- 4 + 6 = 10 → node(0), carry=1  
- 3 + 4 + carry=1 = 8 → node(8)  

**Output:**  
```
[7 → 0 → 8]   // represents 807
```

---

### 📊 Complexity  
- **Time Complexity:** O(max(m, n)) → traverse both lists once  
- **Space Complexity:** O(max(m, n)) → result list size

# 3️⃣ Sort Linked List of 0s, 1s, and 2s

**Difficulty:** 🟢 Easy  
**Tags:** Linked List, Counting Sort  

---

### 🧩 Problem Statement  
Given a linked list containing only values `0`, `1`, and `2`, sort the list so that all `0`s come first, followed by all `1`s, and then all `2`s.  

---

### 💡 Approach (Counting Method)  
1. Traverse the linked list once and **count** the number of `0`s, `1`s, and `2`s.  
2. Traverse the list again and **replace node values** in order:  
   - First fill with `0`s, then `1`s, then `2`s.  
3. Return the modified head.  

⚠️ This approach modifies **data values** instead of rearranging nodes.  
👉 Optimized pointer‑based solution rearranges nodes directly without changing data.

---

### 💻 Your Code (Unchanged)

```cpp
/*
Definition of singly linked list:
class ListNode{
  public:
    int data;
    ListNode *next;
    ListNode() : data(0), next(nullptr) {}
    ListNode(int x) : data(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : data(x), next(next) {}
};
*/

class Solution {
    public:
        ListNode* sortList(ListNode* &head) {
            ListNode* temp = head;
            int count0 = 0, count1 = 0 , count2 = 0;

            while(temp!=NULL){
                if(temp->data == 0) count0++;
                else if(temp->data == 1) count1++;
                else if(temp->data == 2) count2++;
                temp= temp->next;
            } 

            temp = head;
            // replacing values
            while(temp!=NULL){
                if(count0) { 
                    temp->data = 0;
                    count0--;
                }
                else if(count1) {
                    temp->data = 1;
                    count1--;
                }
                else {
                    temp->data = 2;
                    count2--;
                }
                temp= temp->next;
            }

            return head;
        }
};
```

---

### 📝 Input & Output Example  

**Input Linked List:**  
```
head = [1 → 2 → 0 → 1 → 2 → 0]
```

**Step 1 (Counting):**  
- count0 = 2, count1 = 2, count2 = 2  

**Step 2 (Replacing):**  
- Fill first 2 nodes with 0 → [0 → 0 → …]  
- Next 2 nodes with 1 → [0 → 0 → 1 → 1 → …]  
- Last 2 nodes with 2 → [0 → 0 → 1 → 1 → 2 → 2]  

**Output Linked List:**  
```
[0 → 0 → 1 → 1 → 2 → 2]
```

---

### 📊 Complexity  
- **Time Complexity:** O(n) → two traversals of the list  
- **Space Complexity:** O(1) → only counters used

# 4️⃣ Remove Nth Node from End of Linked List

**Difficulty:** 🟡 Medium  
**Tags:** Linked List, Two-Pointer, Simulation  

---

### 🧩 Problem Statement  
Given the head of a linked list, remove the **n-th node from the end** of the list and return its head.  

---

### 💡 Approach (Two-Pass Counting Method)  
1. Traverse the list once to **count total nodes**.  
2. If `n == count`, it means we need to remove the **head node** → return `head->next`.  
3. Otherwise, calculate the position from the start: `res = count - n`.  
4. Traverse again until reaching the node just before the target.  
5. Delete the target node and adjust pointers.  
6. Return the updated head.  

⚠️ This is a **two-pass solution**.  
👉 Optimized solution uses **fast and slow pointers** in one pass.

---

### 💻 Your Code (Unchanged)

```cpp
class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
          ListNode* temp = head;
          int count = 0;
          while(temp!=NULL){
            count++;
            temp = temp->next;
          }

          if(n == count){
            ListNode* newHead = head->next;
             delete(head);
            return newHead; 
          }

          int res = count-n;
          temp= head;
          while(temp!=NULL){
            res--;
            if(res==0){
                break;
            }
            temp= temp->next;
          }
          
         ListNode* delNode =  temp->next;
         temp->next = temp->next->next;
         delete(delNode);

        return head;    
      }
};
```

---

### 📝 Dry Run Example  

**Input:**  
```
head = [1 → 2 → 3 → 4 → 5], n = 2
```

**Step 1:** Count = 5  
**Step 2:** Position from start = 5 - 2 = 3  
**Step 3:** Traverse to node before 3rd (value=3).  
**Step 4:** Delete node with value=4.  

**Output:**  
```
[1 → 2 → 3 → 5]
```

---

### 📊 Complexity  
- **Time Complexity:** O(n) → two traversals of the list  
- **Space Complexity:** O(1) → constant extra space

# 5️⃣ Reverse Linked List

**Difficulty:** 🟢 Easy  
**Tags:** Linked List, Two-Pointer  

---

### 🧩 Problem Statement  
Given the head of a singly linked list, reverse the list and return the new head.  

---

### 💡 Approach (Iterative Pointer Reversal)  
1. Maintain three pointers:  
   - `prev` → initially `NULL`  
   - `temp` → current node (starts at head)  
   - `front` → next node (to preserve link while reversing)  
2. Traverse the list:  
   - Save `front = temp->next`.  
   - Reverse link: `temp->next = prev`.  
   - Move `prev = temp`.  
   - Move `temp = front`.  
3. At the end, `prev` points to the new head.  

---

### 💻 Your Code (Unchanged)

```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* temp = head;
        ListNode* prev = NULL;

        while(temp != NULL){
            ListNode* front = temp->next;
            temp->next = prev;
            prev = temp;
            temp = front;
        }

        return prev;
    }
};
```

---

### 📝 Dry Run Example  

**Input:**  
```
head = [1 → 2 → 3 → 4 → 5]
```

**Step-by-step reversal:**  
- Iteration 1: Reverse 1 → NULL  
- Iteration 2: Reverse 2 → 1  
- Iteration 3: Reverse 3 → 2 → 1  
- Iteration 4: Reverse 4 → 3 → 2 → 1  
- Iteration 5: Reverse 5 → 4 → 3 → 2 → 1  

**Output:**  
```
[5 → 4 → 3 → 2 → 1]
```

---

### 📊 Complexity  
- **Time Complexity:** O(n) → traverse list once  
- **Space Complexity:** O(1) → constant extra space

# 6️⃣ Add One to a Number Represented by Linked List

**Difficulty:** 🟡 Medium  
**Tags:** Linked List, Math, Simulation  

---

### 🧩 Problem Statement  
You are given a non‑empty linked list representing a non‑negative integer.  
- Digits are stored in **forward order** (most significant digit first).  
- Add **1** to the number and return the updated linked list.  

---

### 💡 Approach (Reverse + Carry Propagation)  
1. Reverse the linked list so that addition starts from the **least significant digit**.  
2. Initialize `carry = 1` (since we are adding one).  
3. Traverse the reversed list:  
   - Add carry to current node’s value.  
   - If value < 10 → set carry = 0 and stop.  
   - Else → set node value = 0 and carry = 1 (propagate).  
4. After traversal, if carry = 1 → create a new node with value `1` at the front.  
5. Reverse the list again to restore original order.  
6. Return the updated head.  

---

### 💻 Your Code (Unchanged)

```cpp
class Solution {
    public:
    ListNode *reverse(ListNode *head){
        ListNode* temp = head;
        ListNode* prev = NULL;

        while(temp!=NULL){
            ListNode* front = temp->next;
            temp->next = prev;
            prev = temp;
            temp= front;
        }
        return prev;
    }

    ListNode *addOne(ListNode *head) {
      head = reverse(head);  
      ListNode* temp = head;
      int carry = 1;
      
      while(temp!=NULL){
          temp->val = temp->val + carry;

          if(temp->val < 10){
            carry = 0;
            break;
          }
          else{
            temp->val = 0;
            carry = 1;
          }
          temp = temp->next;
      }
      if(carry == 1){
        ListNode* newHead = new ListNode(1);
        head = reverse(head);
        newHead->next = head;
        return newHead; 
      }

      head = reverse(head);
      return head;
    }
};
```

---

### 📝 Dry Run Example  

**Input:**  
```
head = [1 → 9 → 9]   // represents 199
```

**Step-by-step:**  
- Reverse → [9 → 9 → 1]  
- Add carry=1 → first node becomes 0, carry=1  
- Next node → 9+1=10 → becomes 0, carry=1  
- Next node → 1+1=2 → becomes 2, carry=0  
- Reverse back → [2 → 0 → 0]  

**Output:**  
```
[2 → 0 → 0]   // represents 200
```

---

### 📊 Complexity  
- **Time Complexity:** O(n) → two traversals (reverse + addition + reverse back)  
- **Space Complexity:** O(1) → constant extra space

# 7️⃣ Middle of Linked List

**Difficulty:** 🟢 Easy  
**Tags:** Linked List, Two-Pointer  

---

### 🧩 Problem Statement  
Given the head of a singly linked list, return the **middle node** of the linked list.  
- If there are two middle nodes, return the **second middle node**.  

---

### 💡 Approach (Counting Method)  
1. Traverse the list once to **count total nodes**.  
2. Compute the middle position: `midNode = (count / 2) + 1`.  
   - This ensures that for even length lists, the **second middle** is chosen.  
3. Traverse again until reaching the `midNode`.  
4. Return that node.  

👉 Optimized solution uses **fast and slow pointers** in one pass.

---

### 💻 Your Code (Unchanged)

```cpp
class Solution {
public:
    ListNode* middleOfLinkedList(ListNode* head) {
      ListNode* temp = head;
      int count = 0;

      while(temp != NULL){
        count++;
```

### 🧩 Problem Statement

### 💡 Approach (Counting Method)

2. If only one node → return `NULL`.

5. Delete the middle node and adjust pointers.  
6. Return the updated head.

### 💡 Approach (Stack Method)

```cpp
        temp = temp->next;

};
```

### 🧩 Problem Statement  
Given two singly linked lists that merge into a **Y‑shaped structure**, find the node where they intersect.  
- Intersection is defined by **reference equality** (same node object), not by value.  
- If no intersection exists, return `NULL`.

---

### 💡 Approaches  

#### 1. **Length Difference Method (Your Code)**
- Count lengths of both lists (`lenA`, `lenB`).  
- Advance pointer of longer list by `|lenA - lenB|` steps.  
- Traverse both lists together until pointers meet.  
- Return the meeting node.  

#### 2. **Two-Pointer Switching Method (Optimized)**
- Use two pointers `pA` and `pB`.  
- Traverse both lists; when one reaches the end, switch it to the other list’s head.  
- Eventually, both pointers will meet at the intersection node (or `NULL` if no intersection).  
- This avoids length calculation and works in **O(n + m)** time, **O(1)** space.

---

### 💻 Example Code (Two-Pointer Switching)

```cpp
class Solution {
public:
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        if(!headA || !headB) return NULL;

        ListNode* pA = headA;
        ListNode* pB = headB;

        while(pA != pB){
            pA = (pA == NULL) ? headB : pA->next;
            pB = (pB == NULL) ? headA : pB->next;
        }

        return pA; // either intersection node or NULL
    }
};
```

# 1️⃣1️⃣ Intersection Point of Y‑shaped Linked Lists

**Difficulty:** 🟡 Medium  
**Tags:** Linked List, Two-Pointer  

---

### 🧩 Problem Statement  
Given two singly linked lists that merge into a **Y‑shaped structure**, find the node where they intersect.  
- Intersection is defined by **reference equality** (same node object), not by value.  
- If no intersection exists, return `NULL`.

---

### 💡 Approach (Length Difference Adjustment)  
1. Count lengths of both lists (`cnt1`, `cnt2`).  
2. Identify the longer list.  
3. Advance pointer of longer list by `|cnt1 - cnt2|` steps so both pointers are at the same distance from the end.  
4. Traverse both lists simultaneously until:  
   - Pointers meet → intersection node found.  
   - Both reach `NULL` → no intersection.  

---

### 💻 Your Code (Unchanged)

```cpp
class Solution {
public:
   ListNode* collisionPoint(ListNode* smallerListHead, ListNode* longerListHead, int len){
      ListNode* temp1 = smallerListHead;
      ListNode* temp2 = longerListHead;

      // Adjust the pointers to same level
      for(int i = 0; i < len; i++) temp2 = temp2->next;
      while(temp1 != temp2){
          temp1 = temp1->next;
          temp2 = temp2->next;
      }
      return temp1;
   }

   ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
      ListNode* temp1 = headA;
      ListNode* temp2 = headB;
      int cnt1 = 0;
      int cnt2 = 0;

      while(temp1 != NULL){
         cnt1++;
         temp1 = temp1->next;
      }

      while(temp2 != NULL){
         cnt2++;
         temp2 = temp2->next;
      }

      // Traverse the longer list and bring the pointers to same level
      if(cnt1 < cnt2) return collisionPoint(headA, headB, cnt2 - cnt1);
      return collisionPoint(headB, headA, cnt1 - cnt2);
   }
};
```

# 1️⃣5️⃣ Reverse Nodes in k‑Group

**Difficulty:** 🔴 Hard  
**Tags:** Linked List, Recursion, Simulation  

---

### 🧩 Problem Statement  
Given the head of a linked list, reverse the nodes of the list **k at a time** and return the modified list.  
- Nodes are reversed in groups of size `k`.  
- If the number of nodes is not a multiple of `k`, the remaining nodes are left as is.  
- You may not alter the values in the list, only the nodes themselves.

---

### 💡 Approach (Helper Functions + Iterative Group Reversal)  
1. **Helper 1: `reveseLinkedList`**  
   - Standard iterative reversal of a linked list segment.  

2. **Helper 2: `getKthNode`**  
   - Given a starting node, return the k‑th node ahead.  
   - If fewer than `k` nodes remain → return `NULL`.  

3. **Main Logic: `reverseKGroup`**  
   - Traverse the list in chunks of size `k`.  
   - For each group:  
     - Find the k‑th node.  
     - Disconnect the group.  
     - Reverse the group.  
     - Reconnect with previous group’s tail.  
   - Continue until fewer than `k` nodes remain.  

---

```cpp

public:
    ListNode* reveseLinkedList(ListNode* head){
        ListNode* temp = head;
        ListNode* prev = NULL;
        while(temp != NULL){
            ListNode* front = temp->next;
            temp->next = prev;
            prev = temp;
            temp = front;
        }
        return prev;
    }

    ListNode* getKthNode(ListNode* temp, int k){
        k -= 1;
        while(temp != NULL && k > 0){
            k--;
            temp = temp->next;
        }
        return temp;
    }

    ListNode* reverseKGroup(ListNode* head, int k) {
        ListNode* temp = head;
        ListNode* prevLast = NULL;

        while(temp != NULL){
            ListNode* kThNode = getKthNode(temp, k);

            if(kThNode == NULL){
                if(prevLast) prevLast->next = temp;
                break;
            }

            ListNode* newNode = kThNode->next;
            kThNode->next = NULL;

            reveseLinkedList(temp);

            if(temp == head){
                head = kThNode;
            } else {
                prevLast->next = kThNode;
            }

            prevLast = temp;
            temp = newNode;
        }
        return head;
    }
};
```

---

### 📝 Dry Run Example  

**Input:**  
```
head = [1 → 2 → 3 → 4 → 5], k = 2
```

**Step-by-step:**  
- Group 1: [1 → 2] → reversed → [2 → 1]  
- Group 2: [3 → 4] → reversed → [4 → 3]  
- Remaining: [5] → unchanged  

**Output:**  
```
[2 → 1 → 4 → 3 → 5]
```

---

**Another Example:**  
```
head = [1 → 2 → 3 → 4 → 5], k = 3
```

- Group 1: [1 → 2 → 3] → reversed → [3 → 2 → 1]  
- Remaining: [4 → 5] → unchanged  

**Output:**  
```
[3 → 2 → 1 → 4 → 5]
```

### 📊 Complexity  
- **Time Complexity:** O(n) → each node visited once  
- **Space Complexity:** O(1) → constant extra space

# 1️⃣6️⃣ Rotate List (Right Rotation)

**Difficulty:** 🟡 Medium  
**Tags:** Linked List, Simulation  

---

### 🧩 Problem Statement  
Given the head of a linked list, rotate the list to the right by `k` places.  
- Rotation means moving the last `k` nodes to the front.  
- If `k` is greater than the length, use `k % len`.  

---

### 💡 Approach (Length + Circular Connection)  
1. Handle edge cases: if list is empty, has one node, or `k=0` → return head.  
2. Traverse the list to find its **length** and the **tail node**.  
3. If `k % len == 0` → no rotation needed.  
4. Otherwise:  
   - Connect tail → head (make list circular).  
   - Find the new last node at position `(len - k)` from the start.  
   - Break the circle at this node.  
   - New head = `newLastNode->next`.  

---

### 💻 Your Code (Unchanged)

```cpp
class Solution {
public:
    ListNode* getNewLastNode(ListNode* temp, int k){
        int cnt = 1;
        while(temp != NULL){
            if(cnt == k) return temp;
            cnt++;
            temp = temp->next;
        }
        return temp;
    }

    ListNode* rotateRight(ListNode* head, int k) {
        if (head == NULL || head->next == NULL || k == 0) return head;
           
        ListNode* tail = head;
        int len = 1;
        while(tail->next != NULL){
            tail = tail->next;
            len++;
        }

        if(k % len == 0) return head;
      
        k = k % len;
      
        // attach the tail to the head (circular list)
        tail->next = head;
        ListNode* newLastNode = getNewLastNode(head, len - k);
        head = newLastNode->next;
        newLastNode->next = NULL;

        return head;
    }
};
```

---

### 📝 Dry Run Example  

**Input:**  
```
head = [1 → 2 → 3 → 4 → 5], k = 2
```

**Step 1:** Length = 5  
**Step 2:** k = 2 % 5 = 2  
**Step 3:** Connect tail → head → circular list  
**Step 4:** New last node = position (5 - 2) = 3rd node (value=3)  
**Step 5:** New head = node after 3 → value=4  

**Output:**  
```
[4 → 5 → 1 → 2 → 3]
```

---

**Another Example:**  
```
head = [0 → 1 → 2], k = 4
```

**Step 1:** Length = 3  
**Step 2:** k = 4 % 3 = 1  
**Step 3:** New last node = position (3 - 1) = 2nd node (value=1)  
**Step 4:** New head = node after 1 → value=2  

**Output:**  
```
[2 → 0 → 1]
```

---

### 📊 Complexity  
- **Time Complexity:** O(n) → traverse list once for length + once for new last node  
- **Space Complexity:** O(1) → constant extra space

# 1️⃣7️⃣ Merge Two Sorted Linked Lists

**Difficulty:** 🟢 Easy  
**Tags:** Linked List, Two-Pointer  

---

### 🧩 Problem Statement  
Given two sorted linked lists `list1` and `list2`, merge them into a single sorted linked list and return its head.  
- The merged list should be sorted in ascending order.  
- You must merge by **rearranging pointers**, not by creating new nodes (except dummy helper).

---

### 💡 Approach (Dummy Node + Iterative Merge)  
1. Create a **dummy node** to simplify pointer handling.  
2. Use a pointer `temp` to build the merged list.  
3. Traverse both lists simultaneously:  
   - Compare current nodes of `list1` and `list2`.  
   - Attach the smaller node to `temp->next`.  
   - Advance the pointer in that list.  
   - Move `temp` forward.  
4. If one list ends, attach the remaining nodes of the other list.  
5. Return `dummy->next` as the head of the merged list.  

---

### 💻 Your Code (Unchanged)

```cpp
class Solution {
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
      ListNode* t1 = list1;
      ListNode* t2 = list2;
      ListNode* dummy = new ListNode(-1);
      ListNode* temp = dummy;

      while(t1 != NULL && t2 != NULL){
        if(t1->val <= t2->val){
            temp->next = t1;
            t1 = t1->next;
        }
        else{
            temp->next = t2;
            t2 = t2->next;
        }
        temp = temp->next;
      }

      if(t1 != NULL) {
          temp->next = t1;
      }
      else{
          temp->next = t2;
      }

      return dummy->next;
    }
};
```

---

### 📝 Dry Run Example  

**Input:**  
```
list1 = [1 → 2 → 4]
list2 = [1 → 3 → 4]
```

**Step-by-step merge:**  
- Compare 1 and 1 → attach 1 (list1), advance list1  
- Compare 2 and 1 → attach 1 (list2), advance list2  
- Compare 2 and 3 → attach 2 (list1), advance list1  
- Compare 4 and 3 → attach 3 (list2), advance list2  
- Compare 4 and 4 → attach 4 (list1), advance list1  
- Remaining → attach 4 (list2)  

**Output:**  
```
[1 → 1 → 2 → 3 → 4 → 4]
```

---

### 📊 Complexity  
- **Time Complexity:** O(m + n) → traverse both lists once  
- **Space Complexity:** O(1) → only dummy node used

# 1️⃣8️⃣ Flatten a Linked List

**Difficulty:** 🟡 Medium  
**Tags:** Linked List, Sorting, Simulation  

---

### 🧩 Problem Statement  
Given a linked list where every node has two pointers:  
- `next` → points to the next node in the main list.  
- `child` → points to a sublist.  

Flatten the list so that all nodes appear in a single sorted linked list using the `child` pointer.  

---

### 💡 Approach (Array + Sorting + Rebuild)  
1. Traverse the main list using `next`.  
2. For each node, traverse its `child` list and collect all values in an array.  
3. Sort the array.  
4. Convert the sorted array back into a linked list using the `child` pointer.  
5. Return the new flattened head.  

⚠️ This approach modifies **data structure** by rebuilding a new list.  
👉 Optimized approach merges lists directly without extra array.

---

### 💻 Your Code (Unchanged)

```cpp
class Solution {
private:
    ListNode* convertArrToLinkedList(vector<int>& arr){
        ListNode* dummy = new ListNode(-1);
        ListNode* temp = dummy;

        for(int x: arr){
            temp->child = new ListNode(x);
            temp = temp->child;
        }
        return dummy->child;
    }

public:
    ListNode* flattenLinkedList(ListNode* &head) {
        ListNode* temp = head;
        vector<int> arr;

        while(temp != NULL){
            ListNode* t2 = temp;
            while(t2 != NULL){
                arr.push_back(t2->val);
                t2 = t2->child;
            }
            temp = temp->next;
        }

        sort(arr.begin(), arr.end());
        return convertArrToLinkedList(arr);
    }
};
```

---

### 📝 Dry Run Example  

**Input:**  
```
Main list: 5 → 10 → 19 → 28
Child lists:
5 → 7 → 8 → 30
10 → 20
19 → 22 → 50
28 → 35 → 40 → 45
```

**Step 1:** Collect all values → [5,7,8,30,10,20,19,22,50,28,35,40,45]  
**Step 2:** Sort → [5,7,8,10,19,20,22,28,30,35,40,45,50]  
**Step 3:** Build flattened list using `child` pointer.  

**Output:**  
```
5 → 7 → 8 → 10 → 19 → 20 → 22 → 28 → 30 → 35 → 40 → 45 → 50
```

---

### 📊 Complexity  
- **Time Complexity:** O(n log n) → sorting step dominates  
- **Space Complexity:** O(n) → extra array used
